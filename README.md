# TBT Test Maker

A WordPress plugin for The Blue Tree (thebluetree.pl). Teachers build tests; students take them one question at a time, with every answer saved as they go.

It replaces the QSM plugin on the site. Release 0.1.0 covers multiple-choice tests; gap-fill questions follow in a later release.

Release 0.2.0 adds classes and access: a test can be attached to a TBT Notes class and lesson, can be open to anyone with the link or kept for logged-in students, and reports a logged-in student's score to Class Progress.

Release 0.3.0 adds the teacher's Results screen: who took a test, how they scored, what each person answered, and which questions were hardest.

Release 0.4.0 adds the certificate and the result email: a test can give students a PDF certificate with their name and score, and email them their result when they finish.

Release 0.5.0 adds fill in the gaps: the teacher puts each answer in square brackets, the student types the missing words into the text, and every gap is one point.
