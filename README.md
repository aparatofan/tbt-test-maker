# TBT Test Maker

A WordPress plugin for The Blue Tree (thebluetree.pl). Teachers build tests; students take them one question at a time, with every answer saved as they go.

It replaces the QSM plugin on the site. Release 0.1.0 covers multiple-choice tests; gap-fill questions, class attachment, the teacher's results screen, certificates and result emails follow in later releases.
